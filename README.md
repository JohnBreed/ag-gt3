# AG GT3 Delivery

Public voyage tracker for a 911 GT3 on Höegh Tokyo, bound for Fremantle and
then Sausageworx Garage, Burswood.

**Live site:** https://johnbreed.github.io/ag-gt3/

The page is a static `index.html`. A watch routine updates `data.json` when
a new AIS fix arrives; land outlines live in `coasts.json` and do not change
with each fix.

Positions come from VesselFinder AIS for Höegh Tokyo (IMO 9285483). The ship
photograph is by Andrew Priest, via VesselFinder. Land outlines are from
Natural Earth 110m.
